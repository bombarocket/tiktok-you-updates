# TikTok You Updates

1. Скачай актуальный APK из [Releases](https://github.com/bombarocket/tiktok-you-updates/releases/latest).
2. При первой установке удали обычный TikTok или чужой мод; дальнейшие обновления ставятся поверх.
3. В настройках мода укажи свой бесплатный ключ Gemini API (или используй локальный режим без API).
